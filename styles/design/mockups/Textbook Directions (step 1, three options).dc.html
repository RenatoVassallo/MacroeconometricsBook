5.3 The Minnesota prior

A VAR with n = 7 variables and p = 4 lags has 203 coefficients per draw of the sample. The Minnesota prior answers the count problem by pulling every equation toward a univariate process, so the data only has to overturn a belief rather than build one from nothing (Litterman 1986).

yt = c + A1yt−1 + ⋯ + Apyt−p + ut,  ut ~ N(0, Σ)
(5.1)
Assumption 5.1 — Recursive identification
ut = B0−1εt, with B0−1 lower triangular and 𝔼[εtε′t] = In, so that Σ = B0−1B0−1′.
Margin note. Litterman's original prior treated Σ as fixed and diagonal; the independent Normal-inverse-Wishart version in §5.4 relaxes both.
